# C++ 语言圣经

> 用 C++ 讲 C++。只讨论语法、对象模型与语言特性。

这是一套“自解释”的 C++ 语言教材：每一章都是一个可以编译、运行、修改、破坏的程序。源码是课文，Markdown 是路标，编译器是裁判。

它是 [C 语言圣经](https://github.com/YouKaiGhost/c-bible) 的 C++ 姊妹篇。C 那本回答“C 标准保证了什么”；这一本继续追问：当语言有了引用、类、模板和自动生命周期管理之后，这些问题变成了什么样。

**当前进度：第 0–11 章已完成，覆盖 ISO C++17 的核心语言，并附一个综合练习和一份 C++20/23 速览。**

## 为什么叫“圣经”？

这里的“圣经”不是宗教文本，也不是说它是唯一正确的 C++ 教材。这里的“经”取的是“正经”的意思：一套关于 C++ 语言本身的、尽量回到标准与第一性原理的读本。

本教材只回答这类问题：

- 一个声明到底声明了什么？
- 一个表达式是左值还是右值？它何时、以何种顺序求值？
- 一个对象从哪里开始，到哪里结束？谁负责销毁它？
- 拷贝和移动的区别是什么？编译器什么时候会悄悄生成它们？
- 模板在编译期做了什么？为什么错误信息会那么长？
- 编译器凭什么接受或拒绝一行代码？

它不教你写 GUI，不教你用框架，也不把“常见写法”冒充“语言规则”。遇到标准与实现不一致的地方，会明确区分。

## 这套教材适合谁

- 已经掌握 C，或至少另一门编程语言，想系统补齐 C++ 语法的人；
- 写过 C++，却对引用、RAII、拷贝/移动、模板、链接与 ODR 似懂非懂的人；
- 想从“能跑”走向“知道标准保证了什么”的人。

它不适合完全没写过代码的人，也不是 STL API 手册。标准库只在必要的地方出现，例如 `std::cout`、`std::string`、`std::vector`、`std::unique_ptr`。

## 阅读方法

每章按同一个节奏展开：

1. **读**：先看这一章引入的语法。
2. **跑**：编译并运行完整程序。
3. **拆**：逐节解剖，知道每个字符为什么在那里。
4. **坏**：故意删掉一个分号、改错一个类型、去掉一个 `virtual`，读编译器给的诊断。
5. **练**：做练习，把知识变成手上的动作。

不要只读不跑。C++ 的很多规则，只有在你把代码改坏、看编译器如何反应之后，才会真正变成直觉。

## 开始

要求：一个支持 C++17 的编译器（GCC、Clang 或 MSVC），以及一个终端。源文件使用 UTF-8 编码；MSVC 用户请加 `/utf-8`，否则中文注释可能被按本地代码页解释。

```sh
make          # 构建全部章节
make check    # 用 -Werror 重新构建全部章节
make run      # 构建并依次运行全部示例
```

`make run` 的输出会比较长；想只看某一章，可以直接构建对应目标：

```sh
make 05-arrays-pointers/arrays
./05-arrays-pointers/arrays
```

也可以进入章节目录直接编译：

```sh
cd 00-hello-world
c++ -std=c++17 -Wall -Wextra -Wpedantic hello.cpp -o hello
./hello
```

看到下面这行，就说明工具链和教材都正常：

```text
Hello, World!
```

## 约定

- 以 **ISO C++17** 为基线；涉及 C++20/23 的地方会单独标注。
- 示例尽量只依赖标准 C++ 和宿主环境的最小假设。
- 代码风格是 K&R 的变体：4 空格缩进，左花括号不换行。
- 全程写 `std::`，不写 `using namespace std;`。命名空间不是装饰，它决定了名字从哪里来。
- “实现定义”“未指定”“未定义行为”是三个不同的词，教材会严格使用。
- 每章的 `.cpp` 文件都可以单独编译；第 8 章的多文件程序在根 `Makefile` 里显式链接。

## 验证

本仓库在 GCC 10.2（C++17）下用以下配置验证过：

```sh
make check
```

它会对所有程序使用：

```text
-std=c++17 -Wall -Wextra -Wpedantic -Werror
```

全部程序也用 AddressSanitizer + UndefinedBehaviorSanitizer 运行过一遍。第 10 章会把“邻近 UB 的代码”保留为注释，而不是真的执行；这是故意的。

## 范围

这套教材覆盖 C++17 的核心语言：

- 对象、类型、声明、初始化、转换；
- 表达式、值类别、运算符、求值顺序；
- 控制流、函数、重载、默认实参、lambda；
- 数组、指针、引用、`std::array`、`std::vector`；
- 字符串、字符数组、`std::string`、`std::string_view`；
- 类、构造/析构、RAII、拷贝/移动、继承与虚函数；
- 存储期、链接、ODR、多文件程序、`inline` 变量；
- 函数模板、类模板、特化、可变参数、折叠表达式、`if constexpr`；
- 未定义行为、实现定义、未指定行为与可移植性。

附录补充了 C++20 的概念、范围、协程、模块、三路比较等特性，并给出 C++23 的速览。

它不展开完整 STL、并发与内存模型、网络、GUI、构建系统和 ABI 的全部细节。教材的目标是让你读懂语言本身，而不是背完所有库组件。
